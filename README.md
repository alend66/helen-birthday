# Happy Birthday Helen! 🎂 | Take The Ride & Celebrate

An interactive, responsive birthday celebration website dedicated to Helen Johnson (2026).

## ✨ Features
- **Dynamic Living Sky**: Smooth transition from Golden Dawn → Blue Sky → Amber Sunset → Starry Midnight.
- **Milestone HUD & Odometer**: Tracks journey milestones in real-time from 0 to 2026 km.
- **Vintage Polaroids & Instagram Highlights**: Showcases cherished memories with high-definition lightbox modal.
- **Birthday Boarding Pass**: Direct WhatsApp wish integration (+91 85477 40930).
- **Nightfall Ceremony**: Interactive candle blowing and secret wish reveal ceremony.
- **Celebration Audio & Confetti**: Web Audio API melody and colorful confetti fireworks.
